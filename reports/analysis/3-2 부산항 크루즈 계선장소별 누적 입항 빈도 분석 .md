# 3-2. 부산항 크루즈 계선장소별 누적 입항 횟수 분석

> 2013년 1월 1일부터 2026년 10월 16일까지 부산항 크루즈 입항은 총 1,518회로 집계됐다. 북항크루즈터미널 1선석은 522회, 영도크루즈터미널은 446회였다. 두 장소의 합계는 968회로, 전체의 63.8%를 차지했다.

---

## 1. 요약

### 종합 결론

분석 기간의 크루즈 입항은 일부 계선장소에 집중됐다. 북항크루즈터미널 1선석, 영도크루즈터미널, 국제여객터미널 14선석의 누적 입항 횟수는 합계 1,244회로, 전체 1,518회의 81.9%를 차지했다.

이 결과는 과거에 입항이 많았던 장소를 확인하는 자료로 사용할 수 있다. 운영사는 해당 장소의 최근 입항 일정과 예상 승객 수를 함께 확인해 인력과 시설의 사전 준비에 참고할 수 있다.

다만 장기간의 기록을 합한 결과이므로, 최근에도 같은 장소에 입항이 집중되는지는 연도별 자료로 확인해야 한다.

### 핵심 발견

1. **북항크루즈터미널 1선석의 누적 입항 횟수가 가장 많았다.** 522회로 전체의 34.4%를 차지했다.
2. **영도크루즈터미널은 446회로 두 번째로 많았다.** 북항크루즈터미널 1선석과 합하면 968회로, 전체의 63.8%였다.
3. **상위 3개 장소의 입항 비중은 81.9%였다.** 두 장소에 국제여객터미널 14선석의 276회를 더하면 합계 1,244회였다.
4. **상위 5개 장소의 입항 비중은 98.4%였다.** 상위 5개 장소는 1,493회였으며, 나머지 장소를 합한 ‘기타’는 25회였다.

## 2. 분석 질문과 범위

### 분석 질문

부산항 크루즈는 어떤 계선장소에 많이 입항했으며, 주요 장소가 전체 입항에서 차지하는 비중은 얼마인가?

### 분석 범위

| 구분 | 내용 |
| --- | --- |
| 분석 대상 | 부산항 크루즈 입항 기록 |
| 분석용 파일 | `크루즈입항정보.csv` |
| 분석 기간 | 2013년 1월 1일~2026년 10월 16일 |
| 입항 기록 선정 기준 | 입출 구분이 ‘입항’이고 선박용도가 ‘크루즈선’인 기록 |
| 장소 구분 | `계선장소.2` 열의 장소명 |
| 분석 항목 | 장소별 누적 입항 횟수와 전체 대비 비중 |
| 그래프 표시 범위 | 입항 횟수가 많은 상위 5개 장소와 나머지를 합한 ‘기타’ |
| 2026년 자료 | 1월 1일부터 10월 16일까지의 기록 |

이 보고서에서 **누적 입항 횟수는 분석 기간에 해당 장소로 집계된 입항 기록 수**를 뜻한다. 같은 선박의 서로 다른 입항은 각각 포함한다.

3-1의 ‘입항건수’와 이번 분석의 ‘입항 횟수’는 모두 입항 기록 수를 센 값이다. 같은 1,518건의 기록을 이번 절에서는 1,518회로 표현했다.

3-1에서는 장소별 입항건수와 승객 규모의 차이를 비교했다. 이번 절에서는 같은 입항 집계값을 이용해 상위 2개·3개·5개 장소에 입항이 얼마나 모였는지 살펴본다.

월별·일별 입항 분포, 입항 간격, 승객 수와 체류시간은 이번 분석에 포함하지 않았다.

### 분석 기간

 2013년 1월 1일~2026년 10월 16일이다. 2026년은 1월 1일부터 10월 16일까지의 기록을 포함했다.

 이번 결과는 전체 기간의 누적 실적으로, 최근 한 해의 장소별 이용 현황과는 구분한다.

## 3. 데이터와 방법

- **데이터 출처:**

  PORT-MIS의 「선박입출항현황」에서 확보한 부산항 크루즈 입항 자료를 사용했다. 분석용 파일은 크루즈입항정보.csv이다. 결과는 「부산항 크루즈 계선장소별 입항 빈도」 그래프로 제시했다.

  본문의 수치와 장소명은 노트북에 저장된 그래프 결과를 기준으로 정리했다. 상위 장소들을 합한 비중은 반올림된 개별 비중을 더하지 않고, 입항 횟수를 먼저 합산한 뒤 계산했다.

  코드에는 부산항만 따로 고르는 조건이 없으므로, 분석용 파일이 부산항 자료로 구성돼 있는지 원본에서 확인해야 한다.

- **주요 지표:**

| 지표 | 정의 및 계산 방법 |
  | --- | --- |
  | 장소별 누적 입항 횟수 | 분석 기간에 해당 장소로 집계된 입항 기록 수 |
  | 장소별 입항 비중 | 해당 장소 입항 횟수 ÷ 전체 입항 횟수 × 100 |
  | 상위 장소의 합산 비중 | 상위 2개·3개·5개 장소의 입항 횟수 합계 ÷ 전체 입항 횟수 × 100 |
  | 장소 간 입항 횟수 차이 | 비교 장소의 입항 횟수 − 기준 장소의 입항 횟수 |

  비중의 분모는 전체 입항 횟수 1,518회다. 비중은 반올림 전 집계값으로 계산한 뒤 소수점 첫째 자리까지 표시했다.

- **분석 방법:**

  PyCharm에서 Python 코드를 작성하고 실행했다. pandas로 입항 기록을 정리하고 계선장소별 누적 입항 횟수와 전체 대비 비중을 계산했으며, Plotly로 가로 막대그래프를 작성했다.

  열 이름의 앞뒤 공백을 제거하고, 장소 구분에 사용할 `계선장소.2` 열이 있는지 확인했다. 이후 입출 구분이 ‘입항’이고 선박용도가 ‘크루즈선’인 기록을 선정했다.

  입항일시를 날짜 형식으로 바꾸고, 2013년 1월 1일 이상, 2026년 10월 17일 미만인 기록만 남겼다. 이 조건에는 2026년 10월 16일 하루 전체가 포함된다. 날짜로 바꿀 수 없는 기록은 분석 기간에 해당하는지 판단할 수 없어 집계에서 제외했다.

  계선장소명은 `계선장소.2` 열을 사용하고 앞뒤 공백을 제거했다. 장소명이 비어 있는 경우에는 해당 입항 기록이 집계에서 빠지지 않도록 ‘계선장소 미상’으로 분류하도록 했다. 실제 해당 기록의 유무와 횟수는 전체 장소별 집계표에서 확인해야 한다.

  장소별 입항 기록 수를 세어 입항 횟수가 많은 순서로 정렬했다. 입항 횟수가 같으면 장소명 순으로 정렬한 뒤 상위 5개를 선정했다. 나머지 장소의 입항 횟수는 ‘기타’로 합산했다.

  입항 횟수는 선박명이 비어 있는지와 관계없이 분석 조건에 맞는 기록 수를 기준으로 계산했다. 제공된 코드에는 동일 입항의 중복 기록을 제거하는 과정이 없으므로, 중복 여부는 원본 자료에서 별도로 확인해야 한다.

  장소별 비중은 해당 장소의 입항 횟수를 전체 1,518회로 나누고 100을 곱해 계산했다. 상위 2개·3개·5개 장소의 비중은 해당 장소들의 입항 횟수를 먼저 합산한 뒤 계산했다.

- **판정 기준:**

  개별 장소의 누적 입항 횟수를 비교해 순위와 최댓값을 확인했다. ‘기타’는 여러 장소를 합한 값이므로 개별 시설의 순위로 해석하지 않았다.

  상위 2개·3개·5개 장소의 입항 횟수 합계를 전체 1,518회와 비교해 입항 분포를 확인했다.

  누적 횟수가 많다는 사실만으로 시설 효율이 높거나 최근에도 입항이 많다고 판단하지 않았다. 장소별 운영 기간과 최근 입항 일정을 별도로 확인해야 한다.

## 4. 주요 발견

- **발견 내용:**

  **① 북항크루즈터미널 1선석의 누적 입항 횟수가 가장 많았다.**

  북항크루즈터미널 1선석의 누적 입항 횟수는 522회로, 전체 1,518회의 34.4%를 차지했다. 다음은 영도크루즈터미널 446회, 국제여객터미널 14선석 276회 순이었다.

  북항크루즈터미널 1선석은 영도크루즈터미널보다 76회 많았다.

  **② 상위 2개 장소가 전체 입항의 63.8%를 차지했다.**

  북항크루즈터미널 1선석 522회와 영도크루즈터미널 446회를 합하면 968회였다. 나머지 장소의 입항 횟수는 합계 550회였다.

  분석 기간의 전체 입항 중 절반 이상이 두 장소에 해당했다. 다만 두 장소의 입항이 어떤 연도와 날짜에 집중됐는지는 별도 집계가 필요하다.

  **③ 상위 3개 장소가 전체 입항의 81.9%를 차지했다.**

  상위 2개 장소의 968회에 국제여객터미널 14선석의 276회를 더하면 1,244회였다.

  나머지 장소의 입항 횟수는 합계 274회로, 전체의 18.1%였다. 분석 기간의 누적 입항은 상위 3개 장소에 많이 모여 있었다.

  **④ 상위 5개 장소가 전체 입항의 98.4%를 차지했다.**

  상위 3개 장소에 북항크루즈터미널 2선석 128회와 감만부두 3선석(신선대감만터미널) 121회를 더하면 1,493회였다.

  상위 5개를 제외한 나머지 장소는 ‘기타’로 묶었으며, 합계는 25회였다. 분석 기간의 입항 기록 대부분이 상위 5개 장소에 해당했다.

  ‘기타’ 25회는 여러 장소의 합계다. 어떤 장소가 포함됐는지와 각 장소의 횟수는 전체 장소별 집계표에서 확인해야 한다.

- **근거 수치:**

  **① 계선장소별 누적 입항 횟수**

  | 계선장소 | 누적 입항 횟수 | 전체 대비 비중 |
  | --- | ---: | ---: |
  | 북항크루즈터미널 1선석 | **522회** | **34.4%** |
  | 영도크루즈터미널 | 446회 | 29.4% |
  | 국제여객터미널 14선석 | 276회 | 18.2% |
  | 북항크루즈터미널 2선석 | 128회 | 8.4% |
  | 감만부두 3선석(신선대감만터미널) | 121회 | 8.0% |
  | 기타 | 25회 | 1.6% |
  | **합계** | **1,518회** | **100.0%** |

※ 개별 비중을 각각 반올림했으므로 표시된 비중을 모두 더하면 100.2%가 된다. 합계 행의 100.0%는 전체 입항 횟수 1,518회를 기준으로 계산한 값이다.

  북항크루즈터미널 1선석과 영도크루즈터미널의 차이:

  `522 − 446 = 76회`

  **② 상위 2개 장소의 합계와 비중**

  | 구분 | 누적 입항 횟수 | 전체 대비 비중 |
  | --- | ---: | ---: |
  | 상위 2개 장소 | 968회 | 63.8% |
  | 나머지 장소 | 550회 | 36.2% |
  | **합계** | **1,518회** | **100.0%** |

  계산 근거:

  - 상위 2개 합계: `522 + 446 = 968회`
  - 상위 2개 비중: `968 ÷ 1,518 × 100 ≈ 63.8%`
  - 나머지 장소: `1,518 − 968 = 550회`

  **③ 상위 3개 장소의 합계와 비중**

  | 구분 | 누적 입항 횟수 | 전체 대비 비중 |
  | --- | ---: | ---: |
  | 상위 3개 장소 | 1,244회 | 81.9% |
  | 나머지 장소 | 274회 | 18.1% |
  | **합계** | **1,518회** | **100.0%** |

  계산 근거:

  - 상위 3개 합계: `522 + 446 + 276 = 1,244회`
  - 상위 3개 비중: `1,244 ÷ 1,518 × 100 ≈ 81.9%`
  - 나머지 장소: `1,518 − 1,244 = 274회`

  ※ 세 장소의 표시 비중인 34.4%, 29.4%, 18.2%를 더하면 82.0%가 된다. 이는 각 비중을 반올림한 뒤 더했기 때문이다. 본문에서는 입항 횟수 합계 1,244회로 계산한 81.9%를 사용했다.

  **④ 상위 5개 장소와 기타의 합계 및 비중**

  | 구분 | 누적 입항 횟수 | 전체 대비 비중 |
  | --- | ---: | ---: |
  | 상위 5개 장소 | 1,493회 | 98.4% |
  | 기타 | 25회 | 1.6% |
  | **합계** | **1,518회** | **100.0%** |

  계산 근거:

  - 상위 5개 합계: `522 + 446 + 276 + 128 + 121 = 1,493회`
  - 상위 5개 비중: `1,493 ÷ 1,518 × 100 ≈ 98.4%`
  - 기타 비중: `25 ÷ 1,518 × 100 ≈ 1.6%`

- **비교 기준:**

  2013년 1월 1일~2026년 10월 16일의 입항 기록을 계선장소명별로 집계하고, 누적 입항 횟수가 많은 순서로 비교했다. 같은 선박의 서로 다른 입항은 각각 포함했다.

  상위 2개·3개·5개 장소의 합계를 각각 전체 1,518회와 비교했다. 이 세 집단은 서로 포함되는 관계이므로, 각 합계나 비중을 다시 더하지 않는다.

  비중의 분모에는 ‘기타’를 포함한 전체 입항 기록을 사용했다. 합산 비중은 반올림된 개별 비중을 더하지 않고 입항 횟수를 먼저 합산한 뒤 계산했다.

  ‘기타’는 상위 5개를 제외한 여러 장소의 합계이므로 하나의 개별 시설로 해석하지 않았다. 또한 원자료에 터미널명과 선석명이 함께 표시돼 있어, 이번 결과는 동일한 선석 단위가 아닌 원자료의 장소명별 비교로 해석한다.

  누적 횟수는 장소별 운영 기간이나 이용 가능 일수로 조정한 값이 아니다. 따라서 시설 이용률이나 운영 효율, 최근 입항 순위를 나타내는 것으로 판단하지 않았다.

  실제 운영계획에는 과거 누적 분포와 함께 최근 입항 예정 장소·일정·예상 승객 수·입출항 시각을 확인해야 한다.

## 5. 한계 및 추가 조사 

### ① 분석의 한계

1. **전체 기간을 합한 결과다.**

   장소별 누적 입항 횟수는 알 수 있지만, 어느 달이나 날짜에 입항이 몰렸는지는 알 수 없다. 월별·일별 집계가 필요하다.

2. **장소별 운영 기간의 차이를 반영하지 않았다.**

   운영 시작 시점이나 이용할 수 있었던 기간이 다르면 누적 횟수에도 차이가 생길 수 있다. 운영 기간에 비해 얼마나 자주 이용됐는지 비교하려면 이용 가능 기간을 함께 확인해야 한다.

3. **최근 이용 순위와 다를 수 있다.**

   과거에 입항이 많았던 장소와 최근 입항이 많은 장소가 같은지는 최근 연도별 집계로 확인해야 한다.

4. **장소를 나눈 단위가 같지 않을 수 있다.**

   ‘영도크루즈터미널’처럼 터미널명으로 표시된 장소와 ‘북항크루즈터미널 1선석’처럼 선석명으로 표시된 장소가 함께 있다. 이번 결과는 `계선장소.2`의 장소명별 비교로 해석해야 한다.

5. **장소명의 차이를 통합하지 않았다.**

   앞뒤 공백은 제거했지만, 같은 장소의 다른 이름이나 과거 명칭을 하나로 합치는 과정은 없다. 시설코드와 명칭을 대조해야 한다.

6. **부산항 자료 여부와 중복 기록을 확인해야 한다.**

   코드에는 항명을 부산으로 제한하거나 동일 입항의 중복을 제거하는 과정이 없다. 원본의 범위와 입항 식별 정보를 확인해야 한다.

7. **입항 횟수만으로 필요한 인력과 시설 규모를 정할 수 없다.**

   입항 횟수가 같아도 승객 수와 선박의 체류시간에 따라 업무량이 달라질 수 있다. 예상 승객 수, 동시 접안 여부와 시설 처리 능력을 함께 확인해야 한다.

  ### ③ 추가 조사

  - 먼저 원본의 항구 구분과 입항 식별 정보를 확인해 부산항 자료 여부와 동일 입항의 중복을 점검한다. 날짜로 바꾸지 못한 기록과 장소명이 없는 기록을 확인하고, 계선장소 코드와 공식 명칭을 대조해 같은 장소가 다른 이름으로 집계됐는지 살펴본다.

  ‘기타’에 포함된 25회의 세부 장소와 횟수를 확인한 뒤 전체 장소별 집계표와 대조한다. 기록을 보완하거나 장소를 통합해 집계가 달라지면 합계·비중·순위와 그래프를 함께 수정한다.

  이번 집계의 장소별 입항 횟수와 전체 1,518회는 앞서 확인한 3-1의 입항건수와 일치했다. 다만 같은 원자료를 사용한 두 결과가 일치한다는 사실만으로 원본의 중복이나 누락까지 확인한 것은 아니므로, 원본 검증을 별도로 진행한다.

  이후 다음 가설을 검증한다. 아래 내용은 현재 분석에서 확인된 결론이 아닌 추가 조사 대상이다.

  | 검증할 가설 | 검증 방법 |
  | --- | --- |
  | 최근에도 누적 상위 3개 장소가 전체 입항에서 큰 비중을 차지할 것이다. | 2023~2025년의 연도별 장소 순위와 누적 상위 3개 장소의 합산 비중을 계산해 장기간 비중 81.9%와 비교한다. 2026년은 이전 연도와 동일 기간으로 맞춰 별도로 비교한다. |
  | 장소별 운영 기간을 고려하면 누적 입항 횟수 순위와 다른 결과가 나타날 것이다. | 장소별 이용 가능 기간을 확인하고, 공통 운영 기간의 입항 횟수와 이용 가능 일수당 입항 횟수를 비교한다. |
  | 주요 장소의 입항은 특정 월이나 날짜에 집중됐을 것이다. | 장소별 연도·월·일 단위 입항 횟수를 집계하고, 각 연도의 입항 중 상위 월과 날짜가 차지하는 비중을 확인한다. |
  | 누적 입항 횟수가 적은 장소에서도 특정 시간대에는 운영 부담이 높을 것이다. | 일별 입항 일정과 입출항 시각, 실제 접안 선석 및 하선 인원을 확인하고, 근무 인원·시설 처리 능력·대기시간과 대조한다. |

  실제 운영계획에는 검증된 누적 분포와 최근 입항 예정 장소·일정·예상 승객 수를 함께 제시해, 날짜와 시간대별 인력 및 시설 준비 수준을 검토한다.
