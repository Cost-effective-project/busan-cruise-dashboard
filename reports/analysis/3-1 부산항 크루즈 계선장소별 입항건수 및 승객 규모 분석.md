# 3-1. 부산항 크루즈 계선장소별 입항건수 및 승객 규모 분석

> 2013년 1월 1일부터 2026년 10월 16일까지 북항크루즈터미널 1선석은 입항건수가 522건으로 가장 많았고, 영도크루즈터미널은 승객 수 합계가 1,060,842명으로 가장 많았다. 두 장소는 전체 입항건수의 63.8%, 확인된 승객 수 합계의 71.1%를 차지했다.

---

## 1. 요약

### 종합 결론

분석 기간의 입항과 승객 수는 북항크루즈터미널 1선석과 영도크루즈터미널에 많이 모여 있었다. 두 장소의 입항건수는 합계 968건으로 전체 1,518건의 63.8%였고, 승객 수는 합계 1,972,218명으로 전체 2,772,719명의 71.1%였다.

다만 입항건수가 가장 많은 장소와 승객 수가 가장 많은 장소는 달랐다. 북항크루즈터미널 1선석은 입항건수가 가장 많았고, 영도크루즈터미널은 승객 수가 가장 많았다.

따라서 장소별 운영계획에서는 입항 일정과 승객 규모를 함께 확인해야 한다. 실제 인력과 시설 준비 규모는 최근 입항 일정, 입항별 예상 승객 수와 터미널 이용 시간을 기준으로 검토해야 한다.

이번 결과는 장기간의 누적 실적이다. 최근에도 같은 장소에 입항과 승객이 집중되는지는 최근 연도별·월별·일별 자료로 확인해야 한다.

### 핵심 발견

1. **입항건수가 가장 많은 장소는 북항크루즈터미널 1선석이었다.** 522건으로 전체의 34.4%를 차지했다.
2. **승객 수 합계가 가장 많은 장소는 영도크루즈터미널이었다.** 1,060,842명으로 전체의 38.3%를 차지했다.
3. **주요 두 장소의 승객 수 합계는 1,972,218명이었다.** 반올림 전 집계값으로 계산한 비중은 71.1%였다.
4. **입항건수 순위와 승객 수 순위가 달랐다.** 선정된 5개 장소 중 감만부두 3선석은 입항건수 5위·승객 수 3위였고, 북항크루즈터미널 2선석은 입항건수 4위·승객 수 5위였다.
5. **승객 수 결측 기록은 ‘기타’에 2건 있었다.** 두 기록은 입항건수에 포함됐지만, 해당 인원은 승객 수 합계에 반영되지 않았다.

## 2. 분석 질문과 범위

### 분석 질문

부산항 크루즈는 어떤 계선장소에 많이 입항했으며, 장소별 입항건수와 승객 수의 분포에는 어떤 차이가 있는가?

### 분석 범위

| 구분 | 내용 |
| --- | --- |
| 분석 대상 | 부산항 크루즈 입항 기록과 해당 기록의 승객 수 |
| 분석용 파일 | `크루즈입항정보.csv` |
| 분석 기간 | 2013년 1월 1일~2026년 10월 16일 |
| 입항 기록 선정 기준 | 입출 구분이 '입항'이고 선박용도가 '크루즈선'인 기록 |
| 장소 구분 | `계선장소.2` 열의 장소명 |
| 승객 수 항목 | 원자료의 `승객` 열 |
| 분석 항목 | 장소별 누적 입항건수·승객 수 합계·전체 대비 비중 |
| 장소 선정 기준 | 입항건수 기준 상위 5개 장소 |
| 기타 | 상위 5개에 포함되지 않은 장소의 합계 |
| 승객 수 그래프 순서 | 입항건수 그래프와 같은 장소 순서 |
| 2026년 자료 | 10월 16일까지의 기록 포함 |

승객 수 그래프는 승객 수 기준으로 장소를 다시 선정하거나 정렬한 결과가 아니다. 입항건수 기준으로 선정한 5개 장소와 ‘기타’를 같은 순서로 표시했다.

본문의 장소별 순위는 선정된 5개 장소 안에서 비교했다. ‘기타’는 여러 장소를 합한 값이므로 하나의 개별 시설로 해석하지 않는다.

두 그래프는 분석 기간 전체의 누적 실적이다. 연평균이나 최근 한 해의 실적을 뜻하지 않는다.

입항건수는 분석 조건에 맞는 입항 기록 수다. 같은 선박의 서로 다른 입항은 각각 포함한다.

승객 수는 입항 기록에 적힌 인원을 합산한 값이다. 같은 사람의 반복 방문을 제외한 인원이나 실제 하선 인원을 뜻하는지는 원자료의 항목 설명을 확인해야 한다.

### 분석 기간 

2013년 1월 1일~2026년 10월 16일이다. 2026년은 10월 16일까지의 기록을 포함했다.

## 3. 데이터와 방법

- **데이터 출처:**

  PORT-MIS의 「선박입출항현황」에서 확보한 부산항 크루즈 입항 자료를 사용했다. 분석용 파일은 크루즈입항정보.csv이다. 결과는 「부산항 크루즈 계선장소별 입항건수」와 「부산항 크루즈 계선장소별 승객 수 합계」 그래프로 제시했다.

  본문의 수치와 장소명은 노트북에 저장된 그래프 결과를 기준으로 정리했다. 승객 수 합계와 장소 간 차이, 여러 장소를 합한 비중은 그래프에 저장된 반올림 전 집계값으로 계산했다.

  코드에는 부산항만 따로 고르는 조건이 없으므로, 분석용 파일이 부산항 자료로 구성돼 있는지 원본에서 확인해야 한다.

- **주요 지표:**
  
  | 지표 | 정의 및 계산 방법 |
  | --- | --- |
  | 장소별 입항건수 | 해당 장소에 기록된 분석 조건 충족 입항 기록 수 |
  | 장소별 승객 수 합계 | 해당 장소 입항 기록의 숫자로 확인되는 `승객` 값 합계 |
  | 입항 비중 | 해당 그룹 입항건수 ÷ 전체 입항건수 × 100 |
  | 승객 비중 | 해당 그룹 승객 수 합계 ÷ 확인된 전체 승객 수 합계 × 100 |
  | 장소 간 차이 | 비교 장소의 집계값 − 기준 장소의 집계값 |
  | 승객 수 결측 기록 수 | 승객 값이 비어 있거나 숫자로 변환되지 않은 기록 수 |

  입항 비중의 분모는 전체 1,518건이며, 승객 비중의 분모는 확인된 전체 승객 수 2,772,719명이다.

  여러 장소를 합한 비중은 반올림 전 집계값을 먼저 합산한 뒤 전체 합계로 나누었다. 비중과 비중 차이는 계산을 마친 뒤 소수점 첫째 자리까지 표시했다.

- **분석 방법:**

  PyCharm에서 Python 코드를 작성하고 실행했다. pandas로 입항 기록을 정리하고 계선장소별 입항건수와 승객 수 합계를 계산했으며, Plotly로 가로 막대그래프를 작성했다.

  열 이름의 앞뒤 공백을 제거하고, 집계에 필요한 열이 있는지 확인했다. 이후 입출 구분이 '입항'이고 선박용도가 '크루즈선'인 기록을 선정했다.

  입항일시를 날짜 형식으로 바꾸고, 2013년 1월 1일 이상, 2026년 10월 17일 미만인 기록만 남겼다. 날짜로 바꿀 수 없는 기록은 분석 기간에 해당하는지 판단할 수 없어 집계에서 제외했다.

  `승객` 열의 쉼표와 앞뒤 공백을 제거한 뒤 숫자로 변환했다. 빈칸이나 숫자로 바꿀 수 없는 값은 결측값으로 처리했다.

  계선장소명은 `계선장소.2` 열을 사용하고 앞뒤 공백을 제거했다. 장소명이 비어 있는 경우에는 해당 입항 기록이 집계에서 빠지지 않도록 ‘계선장소 미상’으로 분류하도록 했다.

  장소별 입항 기록 수를 세어 입항건수가 많은 순서로 정렬했다. 입항건수가 같으면 장소명 순으로 정렬한 뒤 상위 5개를 선정했다. 나머지 장소는 ‘기타’로 묶었다.

  각 그룹의 입항건수, 승객 수 합계와 승객 수 결측 기록 수를 계산했다. 승객 수가 비어 있는 기록도 입항건수에는 포함했으며, 승객 수 합계에는 해당 인원을 더하지 않았다. 한 그룹의 승객 수가 모두 비어 있다면 합계를 0명으로 바꾸지 않고 결측값으로 남기도록 했다.

  저장된 그래프 결과에서는 선정된 5개 장소의 승객 수 결측 기록이 각각 0건이었고, ‘기타’에 2건이 있었다. 따라서 전체 승객 수 합계는 이 두 기록의 미확인 인원을 제외한 값이다.

  제공된 코드에는 동일 입항의 중복 기록을 제거하는 과정이 없으므로, 중복 여부는 원본 자료에서 별도로 확인해야 한다.

- **판정 기준:**

입항건수 기준으로 선정한 5개 장소의 입항건수와 승객 수 합계를 각각 비교해 순위와 최댓값을 확인했다.

  여러 장소를 합한 ‘기타’는 개별 장소의 순위 비교에서 제외했지만, 전체 합계와 비중의 분모에는 포함했다.

  북항크루즈터미널 1선석과 영도크루즈터미널은 두 장소의 집계값을 합산해 전체 대비 비중을 계산했다. 표시된 개별 비중을 단순히 더하지 않았다.

  입항 비중과 승객 비중의 차이는 퍼센트포인트(%p)로 표시했다. 이 차이만으로 시설 활용도나 운영 효율을 판단하지 않았다.

  승객 수 결측 기록은 실제 0명과 구분했으며, 누적 실적을 최근 운영 상황이나 향후 예상 수요로 해석하지 않았다.

## 4. 주요 발견

- **발견 내용:**

  **① 북항크루즈터미널 1선석은 입항건수, 영도크루즈터미널은 승객 수가 가장 많았다.**

  북항크루즈터미널 1선석의 입항건수는 522건으로 가장 많았다. 승객 수 합계는 영도크루즈터미널이 1,060,842명으로 가장 많았다.

  북항크루즈터미널 1선석은 영도크루즈터미널보다 입항건수가 76건 많았다. 반면 승객 수는 영도크루즈터미널이 149,466명 많았다.

  입항건수가 많은 장소와 승객이 많이 집계된 장소가 달랐으므로, 입항건수만으로 장소별 승객 대응 규모를 판단하기는 어렵다.

  **② 주요 두 장소는 전체 입항의 63.8%, 승객 수의 71.1%를 차지했다.**

  북항크루즈터미널 1선석과 영도크루즈터미널의 입항건수는 합계 968건이었다. 승객 수는 합계 1,972,218명이었다.

  두 장소는 전체 입항건수 1,518건의 63.8%, 확인된 전체 승객 수 2,772,719명의 71.1%를 차지했다.

  **③ 감만부두 3선석은 입항건수 순위보다 승객 수 순위가 높았다.**

  감만부두 3선석(신선대감만터미널)은 선정된 5개 장소 중 입항건수가 5위였지만, 승객 수 합계는 3위였다.

  국제여객터미널 14선석과 비교하면 입항건수는 155건 적었지만, 승객 수는 151,078명 많았다.

  입항건수가 상대적으로 적더라도 누적 승객 수는 많을 수 있다. 따라서 입항건수 순위만으로 승객 대응 준비의 우선순위를 정하기는 어렵다.

  두 장소 모두 저장된 집계 결과의 승객 수 결측 기록은 0건이었다. 다만 이 차이가 어떤 선박이나 이용 시기에서 비롯됐는지는 입항별 승객 수와 선박 구성을 확인해야 한다.

  **④ 북항크루즈터미널 2선석은 승객 비중이 입항 비중보다 낮았다.**

  북항크루즈터미널 2선석은 입항건수가 128건으로 선정된 5개 장소 중 4위였다. 승객 수는 45,844명으로 5위였다.

  입항 비중은 8.4%, 승객 비중은 1.7%였으며, 반올림 전 비중으로 계산한 차이는 약 6.8%p였다.

  이 차이만으로 시설 활용도나 운영 효율이 낮다고 판단할 수는 없다. 저장된 집계 결과에서 이 장소의 승객 수 결측 기록은 0건이었으며, 차이의 배경은 입항 선박의 구성과 이용 시기를 추가로 확인해야 한다.

  **⑤ 승객 수 결측 기록 2건은 ‘기타’에 포함됐다.**

  저장된 그래프 결과에서 선정된 5개 장소의 승객 수 결측 기록은 각각 0건이었고, ‘기타’에는 2건이 있었다.

  결측 기록 2건도 입항 기록이므로 입항건수에 포함됐다. 그러나 승객 수를 확인할 수 없어 해당 인원은 승객 수 합계에 더하지 않았다.

  따라서 ‘기타’ 25,415명과 전체 2,772,719명은 숫자로 확인되는 승객 수의 합계다. 결측 기록을 실제 승객 수 0명으로 해석하지 않는다.

  원본 확인 후 0명보다 큰 승객 수가 추가되면 ‘기타’와 전체 승객 수 합계가 늘고 장소별 승객 비중도 달라진다.

## 5. 한계 및 추가 조사 

### ① 분석의 한계

1. **장기간의 누적 결과다.**

   최근의 장소별 이용 순위나 현재 운영 상황을 그대로 나타내지는 않는다. 최근 연도별·월별 결과를 별도로 확인해야 한다.

2. **장소별 운영 기간을 반영하지 않았다.**

   운영 시작 시점과 이용 가능 기간이 다르면 누적 실적에도 차이가 생길 수 있다. 누적 합계만으로 시설 효율을 비교할 수는 없다.

3. **장소를 나눈 단위가 같지 않을 수 있다.**

   터미널명과 개별 선석명이 함께 표시돼 있다. 또한 앞뒤 공백은 정리했지만 과거 명칭이나 같은 장소의 다른 이름을 통합하는 과정은 없다. 시설코드와 공식 명칭을 대조해야 한다.

4. **부산항 자료 여부와 중복 기록을 확인해야 한다.**

   코드에는 항명을 부산으로 제한하거나 동일 입항의 중복을 제거하는 과정이 없다. 원본의 범위와 입항 식별 정보를 확인해야 한다.

5. **승객 수 결측 기록의 인원은 반영되지 않았다.**

   결측 기록 2건은 ‘기타’에 포함된다. 해당 인원을 보완하면 전체 합계와 장소별 승객 비중이 달라질 수 있다.

6. **결측 0건이 자료의 완전성을 뜻하지는 않는다.**

   선정된 5개 장소에서는 승객 수 결측 기록이 없었지만, 원본에서 입항 기록 자체가 누락됐거나 값이 잘못 기재됐는지는 별도 확인이 필요하다.

7. **승객 수와 실제 시설 이용 인원은 다를 수 있다.**

   기록된 승객 수가 실제 하선 인원과 같은지는 항목 설명을 확인해야 한다. 누적 합계만으로 동시 접안, 시간대별 혼잡이나 인력 부족을 판단할 수는 없다.

### ③ 추가 조사

 - 먼저 원본의 항구 구분과 입항 식별 정보를 확인해 부산항 자료 여부와 동일 입항의 중복을 점검한다. 계선장소 코드와 공식 명칭을 대조해 같은 장소가 다른 이름으로 기록됐는지, 터미널과 개별 선석이 어떤 단위로 구분됐는지 확인한다.

‘기타’에 포함된 25건의 세부 장소와 승객 수 결측 기록 2건의 원본을 확인한다. 장소명이 없는 기록의 유무도 점검하고, 확인 가능한 장소명과 승객 수를 보완한다. 확인되지 않은 승객 수는 임의로 0명으로 처리하지 않는다.

저장된 장소별 승객 수 합계 2,772,719명은 앞서 확인한 1-2의 연도별 승객 수 합계와 일치했다. 다만 두 집계가 같은 원자료를 사용했다면 공통으로 포함된 누락이나 오류까지 확인한 것은 아니므로, 원본 검증을 별도로 진행한다.
